# TranslatePopup

Windows上でテキストを選択すると、その近くに翻訳ボタンが現れ、クリックするとその場で翻訳結果を表示するポップアップ翻訳ツールです。

## 主な機能

- Windows上のほぼ任意のアプリ（メモ帳、ブラウザ、Office、VS Codeなど）で、テキストを選択すると選択箇所の右下に翻訳ボタンが出現
- 選択を解除する（別の場所をクリックする）とボタンは消える。別のテキストを選択すると、ボタンはその位置に移動
- ボタンをクリックすると翻訳結果ウィンドウを表示（右上に閉じるボタン、左上に翻訳先言語の選択、下部に翻訳結果。ウィンドウはリサイズ可能で、結果表示エリアはウィンドウサイズに追従して伸縮）
- ボタン・翻訳ウィンドウの表示中もタスクバーアイコンは常に非表示。アプリはシステムトレイに常駐し、右クリックメニューから「設定」「終了」を行う
- 翻訳エンジンは Microsoft Translator（Azure Cognitive Services Translator Text API）を使用

## 動作環境

- Windows 10 / 11
- .NET 8 SDK（ビルド・実行に必要。[dotnet.microsoft.com](https://dotnet.microsoft.com/) から入手）
- Azure Translator リソースの APIキー（[Azure Portal](https://portal.azure.com) で「Translator」リソースを作成すると取得可能。無料枠あり）

## ビルド・実行

```powershell
dotnet build TranslatePopup.sln
dotnet run --project src\TranslatePopup\TranslatePopup.csproj
```

初回起動時、APIキーが未設定の場合は自動的に設定画面が開きます。

## 使い方

1. タスクトレイの通知領域アイコンを右クリック →「設定」から Azure Translator の APIキー（および必要であればリージョン）と既定の翻訳先言語を入力して保存
2. 任意のアプリでテキストをドラッグ選択（またはダブルクリック／Shift+クリックで選択範囲を拡張）
3. 選択範囲の右下に表示される「訳」ボタンをクリック
4. 翻訳結果ウィンドウが開く。左上のドロップダウンで翻訳先言語を変更すると再翻訳される。右上の×で閉じる

## プロジェクト構成

```
src/TranslatePopup/
  App.xaml(.cs)          アプリのエントリポイント（タスクバー非表示・トレイ常駐の起点）
  Models/                 設定・言語・翻訳結果のデータモデル
  Services/               設定の永続化、Translator APIクライアント、トレイアイコン管理
  Interop/                Win32 P/Invoke層（グローバルマウスフック、クリップボード操作、
                           Ctrl+C合成送出、DPI変換、前面ウィンドウ監視）
  Selection/               選択検知のオーケストレーション（SelectionWatcher）
  UI/                     翻訳起動ボタン・翻訳結果ウィンドウ・設定画面
```

### 選択検知の仕組み（概要）

UI Automationではなく、クリップボード経由の方式を採用しています。マウスのドラッグ／ダブルクリック／Shift+クリックを検知すると、内部的に Ctrl+C を合成送出してクリップボードの変化を読み取り、直後に元のクリップボード内容へ復元します。この方式はほぼ全てのアプリで動作しますが、以下の制限があります。

- キーボード操作のみでの選択解除（矢印キーなど）は検知できません
- 管理者権限で実行中のアプリ（例: 管理者権限のコマンドプロンプト）は、UIPI により非管理者権限の本アプリからは検知できません

## 設定ファイル・ログ

- 設定: `%AppData%\TranslatePopup\settings.json`
- 診断ログ（デバッグ用、起動のたびに上書き）: `%AppData%\TranslatePopup\logs\debug.log`

## トラブルシューティング

翻訳ボタンが出ない、クリックしても反応しない等の問題が起きた場合は、上記の診断ログを確認してください。マウスイベントの検知結果、クリップボードの変化検知、ボタンのクリック処理、翻訳ウィンドウの表示タイミングが記録されます。
